リポジトリのメインページ右の `Deployments` にデプロイ結果とURLがある

## 自動デプロイ方法

1. リポジトリの `Settings` > `Pages` をクリック
2. `Source` に `Deply from a branch` を選択
3. `Branch` にデプロイ対象ブランチとフォルダを選択
4. `Save` をクリック
5. `Actions` でデプロイが行われる
